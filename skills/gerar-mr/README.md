# gerar-mr

**Autor:** [ricardoalves-dev](https://github.com/ricardoalves-dev)

Gera o conteúdo de um Merge Request a partir das alterações da branch atual.

## Quando usar

- "gere o MR"
- "gere o merge request"
- "finalize a feature"
- `/gerar-mr`

## Instalação

```bash
npx skills add GualterAlbino/IAToolkit --skill gerar-mr
```
