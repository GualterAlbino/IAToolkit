# organizar-imports

**Autor:** [ricardoalves-dev](https://github.com/ricardoalves-dev)

Organiza e agrupa imports de um arquivo TypeScript por escopo, em ordem crescente.

## Quando usar

- "organize os imports deste arquivo"
- `/organizar-imports`

## Instalação

```bash
npx skills add GualterAlbino/ClaudeCodeSkills --skill organizar-imports
```
